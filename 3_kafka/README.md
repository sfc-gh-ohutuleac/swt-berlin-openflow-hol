# Use Case 3 - Ingest data from a Kafka topic

In this lab you will ingest data from a Kafka topic into Snowflake using the Openflow Kafka Connector.

This use case is designed as a **self-paced exercise** that you can complete on your own time after the hands-on lab session at the summit. Follow the quickstart guide below to work through it at your own pace:

[Getting Started with the Openflow Kafka Connector](https://www.snowflake.com/en/developers/guides/getting-started-with-openflow-kafka-connector/)
